# sysup

`bin/sysup` is the source for the step list and line formats. Self-check: `bin/lib/test-sysup` stubs every external command on PATH. These are the constraints the code doesn't show.

- **Report contract**: every step ends in one status line (`ok`, `changed`, `notice`, `fail`; `test-sysup` asserts it). A failed step after the opening `sudo -v` never aborts the run. Full output goes to the log. A `changed` line only appears when the step really changed something, so steps compare before and after instead of parsing messages.
- **Directory**: it runs from `$HOME`, so a project's `mise.toml` can't widen `mise upgrade` to that project's tools.
- **Packages**: `changed` comes from diffing `mise bootstrap packages status --json` before and after the upgrade, not from mise's output. sysup passes no GitHub token: mise asks gh for one itself (`[settings.github] credential_command` in the mise config), because tap formulae resolve through GitHub's API and one run can use up the anonymous limit. On a Mac Homebrew set up, mise is still Homebrew's copy (its keg disables self-update) and Homebrew-installed casks that don't update themselves stay as they are: each gets one notice naming `migrate/legacy-to-mise --step packages`, which does not exist until Part B lands.
- **macOS**: an update whose list entry says `Action: restart` is only downloaded by `-ia` without `--restart`, and a plain restart doesn't install it (checked 2026-10-27), so the summary names Software Update's Restart Now or `softwareupdate -ia --restart`. sysup never restarts. Only those updates need the owner password (Apple Silicon owner authorization; sudo and Touch ID don't count). It comes from `op read` when `DOTFILES_MAC_PASSWORD_OP` is set in `~/.zsh.local` and `op` is on PATH, else from sysup's own hidden prompt, and goes in through `--stdinpass`. softwareupdate must never prompt itself: with its output piped to the log, its prompt echoed the password. A rejected password is a `fail` line with no retry.
- **Rust**: `rustup` (a `brew:` package) runs through `$HOMEBREW_PREFIX/opt/rustup/bin/rustup` when it exists, because a mise shim earlier on an activated PATH would otherwise win. A shim left by a rust toolchain no config pins gets a notice to remove the install dir and `mise reshim`, not `mise prune`, which runs that shim and hangs. So prune is skipped while that dir exists and is bounded by `timeout 600`. `cargo --version` is the same probe Hindsight's daemon preflight runs, and a shell older than the rustup PATH entry fails it, which is why it is a notice.
- **mise**: `mise prune --yes` runs before `mise upgrade`, deleting what the previous run replaced and keeping what this run replaces, so an upgrade can be rolled back until the next run.
- **Claude Code**: `claude update` is read through two `claude --version` calls because its message isn't parsed. `claude plugin update -y` accepts a marketplace-declared install command unseen, a trust the tracked marketplaces have earned. Plugins blocked by a managed policy collapse into one notice. `claude-config retire` runs before `claude-config save`, or save would undo a pull's cleanup on this Mac. It only removes: sysup must not run `restore settings`, which would apply newly pulled permission grants unreviewed and bring back a rule revoked on this Mac. `save` is skipped with an action when `restore --dry-run` finds plugins or settings this Mac lacks, because it would erase them from the tracked files.
- **mise MCP check**: a user-scope entry whose command isn't `$(command -v mise) mcp` is re-registered. `tools fetch failed` is a notice because re-registering can't fix anthropics/claude-code#88128; anything else is a `fail` line with the commands. A missing entry stays silent.
- **Hindsight**: the newer-release notice only fires once npm's `min-release-age` would let it install, and the installer's first `▲` warning becomes a notice (the rest stay in the log), since each means the daemon can't cold-start from that shell.
- **CA roots**: with `DOTFILES_TRIM_CA_ROOTS` set (in `~/.zsh.local`, or with `mise set --override`, which wins), `ca-roots trim` runs only where Homebrew's `emudhra_certificates.rb` exists, since it runs that script and mise doesn't install it; elsewhere the step is a notice. It renews sudo first when a root is present, because the package upgrade can outlast sudo's timeout.
- **Docker Compose**: `sysup` won't notice the fix `bin/docker-devcontainer` waits for, because the compose plugin in use is OrbStack's, not the `docker-compose` formula's.
