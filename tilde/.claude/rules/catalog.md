# Catalog of installed Claude Code tools

A catalog of every installed skill, slash command, subagent and MCP server — with descriptions, a "which to pick" task guide and usage — is at `~/.claude/catalog/CATALOG.md` (quick version: `CATALOG-lite.md`). Check it when choosing a tool for a task instead of guessing from names. Rebuild it with `claude-catalog` after installing, updating or removing plugins (`upup` also rebuilds it).
