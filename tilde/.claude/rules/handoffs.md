# Session handoffs

Applies to handoff notes (`/remember`, `.remember/remember.md`) and to resuming from one.

- An open question names the check that settles it (a file, URL or command). Drop items the repo already answers, and when resuming, run the check before asking the user again.
- A workaround line says what it works around and the evidence that it still helps. A line inherited from the previous handoff without that check is dropped, not copied forward.
- When the next step belongs to a program with a spec, the handoff names the spec, and resuming starts by reading its goal and its list of the owner's decisions in full, before the phase brief. A brief or a handoff line that contradicts a decision is wrong. Check a question or an option against that list first: one a decision already answers is not raised again.
