# Hindsight memory

Long-term, per-repo memory for Claude Code and Codex, through the `@vectorize-io/hindsight-coding-agents` hooks and a local `hindsight-embed` daemon (profile `coding-agent`, port 9077). The vendor's `hindsight-coding-agent` skill explains the tools (`hindsight_search_knowledge_pages` first for project questions, `hindsight_reflect` for why questions, `hindsight_ingest_document` for corrections and durable findings, `hindsight_capture_initiative` when a plan is agreed or materially changes). This rule covers what this machine does differently.

- **Opt-in by path.** Memory is active only under the prefixes in `~/.hindsight/coding-agent.json` (`~/dev` by default). The 🧠 banner at session start names the bank (`coding-agent::<repo>`); no banner means no memory here, so don't call the tools or credit memory.
- **Credit and verify.** Recalled memory and knowledge pages are leads, not evidence (`verify-first.md`). Credit memory only when it informed the answer, and when the code or git contradicts it, write a `Correction: <topic>` document instead of ignoring it.
- **Manage it with `hindsight-memory`, not `npx`.** `paths add|remove <dir>`, `on|off` (kill switch), `survey on|off`, `status`, `uninstall`. The package version is pinned in `bin/hindsight-memory` (`CODING_AGENTS_VERSION`) and `autoUpdate` is off, so a bare `npx @vectorize-io/hindsight-coding-agents install` or `update` would drift from the pin; `upup` runs the pinned upgrade and reports a newer release.
- **Subscription, not an API key.** Extraction runs through the `claude` CLI (`HINDSIGHT_API_LLM_PROVIDER=claude-code`, set in `tilde/.zshenv` and in the Claude Code settings `env`). The models are pinned beside it, Haiku 5.5 for extraction and consolidation and Sonnet 5.5 for reflect and the page refresh (why: `docs/superpowers/specs/completed/2026-10-24-hindsight-memory.md`). Never set an `*_API_KEY` for it, and don't write one into the config or the daemon profile.
- **Costs to know.** The codebase survey is off (a `claude -p` agent samples the repo, untracked files included). A session's first prompt gets the knowledge pages matching it (`autoInject: pages`, retrieval only, no model call), because auto-injected reflect timed out at 20 s on every measured start. `grep inject_pages ~/.hindsight/coding-agents-logs/diag.jsonl` shows those injections. Pages refresh every six hours at a hashed minute (`H */6 * * *`), skipped when nothing changed. `hindsight-memory status` lists the last 24 h of model calls per bank and model from the daemon's request log.
- **Tool guide.** `toolGuideExtra` in the config carries one verify-first sentence that every harness injects, Codex included.
- **Cold start needs `cargo`.** The daemon's cold-start preflight needs `cargo` on PATH, so a shell opened before the rustup PATH entry landed can't start it; `upup` warns when `cargo` is missing and surfaces the installer's own ▲ warnings as notices.
