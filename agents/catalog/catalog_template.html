Claude Code Catalog

How to read this page (click any name to copy its invocation)
  • skill / command type /name in Claude Code; an agent calls its Skill tool with the name.
  • agent not in the / menu. Ask Claude to delegate, e.g. "use the name agent to…" (Agent tool, subagent_type).
  • mcp tools appear as mcp__…__tool. Ask for the task; Claude calls the tools. Manage with /mcp.
  • ★ Recommended: the go-to choice for that task when several tools overlap. Chosen by hand (the pick list in curated.toml), not computed; groups without a clear default have no star.
  • Status tags: alternative in a task group but not its pick · duplicate same job as another item · ungrouped not yet sorted into any task group · internal run by its own plugin, not by you · retired marked for removal · new appeared since the last build.
  • Plugins tab: context cost, usage and cleanup status per plugin. Plugins are the unit you can remove, so cleanup is judged there.
