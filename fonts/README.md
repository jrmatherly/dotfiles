# Fonts

- [MonoLisa](https://www.monolisa.dev/) — paid font with no Homebrew cask, so it's a manual install: select **MonoLisa** in `bin/brewpick` to open its download page (`brewpick --all` skips it). Optional and not used by default — the terminal-side configs use Hack Nerd Font Mono instead (below).
- [Nerd Fonts](https://www.nerdfonts.com/) — installed as casks by the [Brewfile](../setup/Brewfile): Anonymice, FiraCode, Hack, ProFont, SauceCodePro, Tinos and Ubuntu Nerd Fonts. **Hack Nerd Font Mono** is used by Ghostty, cmux (terminal and Markdown viewer), fastfetch (as its displayed Font value), Obsidian's monospace font, Nimble Commander's terminal and viewer, and the Firefox Developer Edition config. FiraCode Nerd Font Mono is VS Code's fallback font.
- [Iosevka Code](https://github.com/amnweb/Iosevka-Code) — the SpaceBox theme's companion font (a custom Iosevka build, SIL OFL 1.1), used by VS Code for the editor and terminal ([vscode/User/settings.json](../vscode/User/settings.json)). It has no Homebrew cask, so [`bin/install-iosevka-code`](../bin/install-iosevka-code) downloads the Nerd Font release zip and unpacks its TTFs into `~/Library/Fonts`. `setup.sh` (misc step) and `upup` both run it:
  - It records the zip's SHA-256 and ETag next to the fonts (`~/Library/Fonts/.IosevkaCodeNerdFont.*`) and sends the ETag on the next run, so an unchanged zip isn't downloaded again.
  - When upstream replaces the zip, the new one is installed automatically. The script also carries the SHA-256 of the zip that was reviewed (`REVIEWED_SHA256`): a zip that differs is still installed, with a notice on every run until that value is updated.
