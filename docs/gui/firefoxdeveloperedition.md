# Firefox Developer Edition

> Optional — not installed by setup; install manually if you use it. Config: `firefox/README.md`.

## Basic

- **Cmd+1** … **Cmd+8:** switch to tab 1–8
- **Cmd+9:** go to the last tab
- **Cmd+Shift+[** / **Cmd+Shift+]:** previous/next tab
- **Cmd+L:** focus the address bar
- **Cmd+Shift+T:** reopen the last closed tab
- **Cmd+Shift+B:** toggle the bookmarks toolbar

## Search

- **Cmd+F:** find in page
- **'** (apostrophe): quick find in links only
- In the address bar, type **@tabs** then **Space** to search open tabs
- In the address bar, type **@bookmarks** then **Space** to search bookmarks

## DevTools

- **Cmd+Option+I:** open DevTools
- **Cmd+Shift+D:** toggle DevTools between the last two docking positions
