# Adobe Lightroom

> Optional — not installed by setup; install manually if you use it. The shortcuts below are Adobe's defaults for Lightroom Desktop (macOS), checked on 2026-10-24 against the page listed under Sources.

## Basic

- **Cmd+F:** search
- **Cmd+,:** preferences
- **Cmd+E:** export with the previous settings; **Shift+E:** export dialog
- **Shift+Cmd+I:** add photos
- **Shift+Cmd+E:** edit in Photoshop

## View

- **P:** Photos panel
- **Shift+P:** Presets panel
- **/:** show / hide the Filmstrip
- **\\:** show original
- **G:** grid
- **D:** Detail
- **F:** full screen; **Shift+Cmd+F:** enter full screen
- **Space:** toggle zoom states
- **Cmd+= / Cmd+-:** zoom in / out
- **Cmd+0:** show / hide the histogram
- **K:** Keywords panel
- **I:** Info panel
- **Cmd+1 … Cmd+6:** expand / retract the Light, Color, Effects, Details, Optics and Geometry panels

## Tools

- **E:** edit
- **C:** crop and rotate; **Cmd+[ / Cmd+]:** rotate left / right
- **Shift+A:** auto tone
- **B:** adjustment brush; **H:** healing brush; **[ / ]:** brush size; **Shift+[ / Shift+]:** brush feather
- **L / R:** linear / radial gradient
- **W:** white balance sampler
- **J:** toggle clipping indicators
- **O:** cycle overlay; **Shift+O:** cycle mask color
- **Shift+G:** guided upright
- **Shift+M:** create version; **Shift+V:** Versions panel

## Rating and flagging

- **Z:** pick; **U:** remove the pick flag; **X:** reject
- **0 … 5:** set the star rating
- **Delete:** remove photo
