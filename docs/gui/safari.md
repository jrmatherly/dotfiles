# Safari

> Requires the web developer features: **Safari → Settings → Advanced → Show features for web developers** (`set-defaults` doesn't configure Safari).

## Web Inspector

- **Cmd+Option+I:** open/close Web Inspector; **Cmd+Option+Shift+I:** connect Web Inspector (Develop menu)
- **Cmd+Shift+D:** switch to the previous docking configuration
- **Cmd+Option+C:** JavaScript console; **Cmd+Option+U:** page source; **Cmd+Option+A:** page resources
- **Ctrl+Cmd+R:** responsive design mode; **Cmd+Shift+C:** start element selection; **Cmd+Option+E:** empty caches
