# Rectangle

> [!NOTE]  
> Optional — not installed by setup; install it yourself (`brew install --cask rectangle`) if you use it. Window management in this setup is handled by Raycast (`help gui/raycast`).

## Import the config

[RectangleConfig.json](RectangleConfig.json) holds the full Rectangle configuration. Either:

- Use the import button in the **Settings** tab of Rectangle's preferences window, or
- Copy it to `~/Library/Application Support/Rectangle/RectangleConfig.json` before launching Rectangle. It loads the file on launch, then renames it with a date/time stamp so it isn't read again.

(Both methods per the [Rectangle README](https://github.com/rxhanson/Rectangle#import--export-json-config).)

## Shortcuts in this config

- `Maximize`: Cmd + Option + F
- `Left Half`: Cmd + Option + Left
- `Right Half`: Cmd + Option + Right
- `Center`: Cmd + Option + C
- `Toggle Todo`: Ctrl + Option + B; `Reflow Todo`: Ctrl + Option + N (only active in Todo mode, which this config leaves off)
